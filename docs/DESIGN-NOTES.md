# Visual direction

`user-provided-github-layout-reference.png` is the original reference screenshot provided for the redesign, not an output screenshot of the React application.

The new homepage follows its recognizable information architecture: dark platform-style header, repository subnavigation, large circular avatar and left profile column, README panel, social badges, tech stack, pinned projects, and activity/stats area. The implementation keeps the original portfolio person's identity and content.

Polish added: consistent 8–12px spacing scale, responsive two-column to stacked layout, visible keyboard focus, genuine interactive repository search/filter, detail dialogs, verified-only optional public GitHub account totals and non-fabricated project metrics. The actual GitHub contribution graph and star counts are deliberately not guessed.

The creative legacy homepage and HTML/PDF résumé remain available under `/creative` and `/resume`.
